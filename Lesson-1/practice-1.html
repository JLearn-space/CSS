Урок 1: Синтаксис и подключение CSS

Эта страница демонстрирует три способа подключения стилей CSS.

Этот параграф стилизован через inline-стили (атрибут style).

Обычный параграф без inline-стилей — его стили заданы во внешнем файле css/style.css.

Внутренний стиль (второй способ)

Заголовок h2 и этот параграф стилизованы через внутренний блок <style> в секции <head>.

Группированный селектор

Заголовки h1, h2 и h3 используют одинаковый шрифт — это достигается группировкой селекторов через запятую.

Внешний файл стилей

Основные стили страницы (фон, шрифт, цвета параграфов) заданы во внешнем файле css/style.css, который подключён через тег <link>.

Этот блок использует класс .container, определённый во внешнем CSS-файле.

Все три способа подключения CSS можно комбинировать на одной странице.
