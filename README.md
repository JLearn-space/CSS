# Курс «CSS: за 10 уроков» / "CSS: in 10 lessons"

> Курс состоит из **10 тем** и посвящён каскадным таблицам стилей CSS — от первого подключения стилей до самостоятельной стилизации и публикации полноценного веб-проекта. По завершении обучения студент умеет создавать адаптивные, семантически стилизованные веб-страницы, владеет Flexbox, Grid, позиционированием и основами анимации.
>
> The course consists of **10 lessons** dedicated to CSS (Cascading Style Sheets) — from first stylesheet connection to full project styling and publishing. Upon completion, students can create responsive, semantically styled web pages using Flexbox, Grid, positioning, and animation basics.

## Предварительные требования / Prerequisites

Для прохождения этого курса необходимы базовые знания HTML (структура документа, семантические теги, формы, таблицы). Рекомендуется пройти курс [«HTML: за 10 уроков»](https://github.com/Saydullayev017/HTML) перед началом обучения.

To take this course, basic HTML knowledge is required (document structure, semantic tags, forms, tables). It is recommended to complete the ["HTML: in 10 lessons"](https://github.com/Saydullayev017/HTML) course before starting.
